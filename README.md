# quant-agent — A股量化研究系统（纸面回测）

以"AI 提假设 + 确定性代码回测判定"为方法论的研究自动化系统。所有收益数字均来自
实际运行的回测；交易规则、指标、晋级 Gate 为确定性组件，LLM 仅有建议权。
point-in-time 数据血缘、封存测试集隔离、失败实验全留存。

## 系统状态

- **宪法版本**：constitution_009（预注册制实验管理 + 预算台账）
- **冻结基线**：baseline_006（10 日持有，IS −5.4% / DEV +55.0% / Sharpe 3.16）
- **当前结论**：批次七至九共 12+1 个变体（含诊断变体），无一通过冻结门槛晋级；
  瓶颈定位在信号质量而非机会范围（日闸消融 E5：DEV +75% 但跨期不一致）

## 关键纪律（摘自任务书）

- REJECT = 证据完整但违反预设门槛；NEEDS_MORE_TESTING = 证据缺失。两者不混用。
- 每轮只改一个核心逻辑，参数与门槛在看结果前固定。
- 重叠窗口不算独立成功案例；半年年化 >100% 不认定目标已实现。
- 研究目标（扣费后年收益 100%）为待验证目标，不允许为达标修改统计口径。
