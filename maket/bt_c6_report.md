## 0. 诚实性声明（先读）
- **这是对仓库现行策略（`screen_candidates.py`）的事后检验**。C6 假设来自 GitHub 碗口反弹策略，**原仓库零回测证据**，本测试是其第一份量化证据。
- 结论只作 **C6 采纳证据**（门槛：A/B 样本≥10、3指标方向一致率≥70%、有经济学解释），**不等于采纳决定本身**。
- 口径对齐：现行条件逐条复刻 `screen_candidates.analyze()`（昨收>MA20、ret20>0、当日涨幅<5%、ATR14∈[1.2%,6.5%]、收阴或距20日高回撤∈[-10%,-2%]，另剔 ST/退）；stock-day 额外要求≥60日历史。

## 1. 数据与样本
- 宇宙：妙想API"成交额>3亿、涨跌幅-6~6、股价>3元"A股（**API上限200行**，返回即成交额前200，实际下限16.9亿，快照日2026-09-22）；ST/退剔除；**未调用限额回退方案**。
- 日线：腾讯 qfq 120根/只，200只全部抓取成功，缓存 `bt_cache_c6_daily.json`（断点续抓，请求间隔0.16s）。
- 有效窗口：2026-03-13 ~ 2026-09-22（约6个月，anchor 条件约束下产生 **60 个有效交易日**）。
- **数据缺口显式标注**：3只票历史不足60日（新上市）整体剔除；anchor 无次日数据=0；anchor 与次日间隔>7自然日（停牌缺口）=0；OHLC 非法=0；碗口窗口量数据缺失=0。**无任何默认值填充**。
- 已知偏差：宇宙为**静态快照**（按2026-09-22成交额选股），历史逐日未重放妙想预筛（成交额/涨跌幅当日口径），存在轻微软件性幸存者偏差。

## 4. 采纳证据门槛核对
| 门槛 | 结果 | 判定 |
|---|---|---|
| 样本≥10 | A=1115、B=284（均≥50，检验充分） | 通过 |
| 方向一致率≥70%（触线/达标/净益3指标 A>B） | **1/3 = 33%** | **不通过** |
| 经济学解释 | "最大阴量=大资金出逃"在方向上应压制次日触线与反弹；实测三指标均无显著改善，且唯一接近显著的检验（净益，p=0.074）**方向与假设相反**（B 组反而略好） | 不支持 |

## 5. 结论：**否决（本轮证据不支持采纳 C6）**
1. C6 对触线率无显著提升（t=1.51, p=0.137），对达标率无提升（B 略优），对 T 回合净收益为**零改善或轻微反向**；按 C6 剔除 B 组会使池内 EV 从 −0.438% 微恶化到 −0.449%，同时池容量缩水 20.3%，纯粹是负期望的收紧。
2. 方向一致率 33% 远低于 70% 门槛；本宇宙为高流动性大票（≥16.9亿成交额），"巨量阴线出逃"逻辑更可能在小票/情绪票栖息地成立，与本系统宇宙错配。
3. 与现行条件共线：现行已要求"收阴或健康回踩"，C6 再剔量能结构的边际信息在本样本中≈0。

## 6. 若要继续检验（扩样建议）
- 拉长历史至 250–500 根日线（回溯 2024），把 60 个交易日扩到 ~300 个，检验跨市场状态稳健性；
- 宇宙下沉到成交额 3–16 亿中票（API 单查询上限200行，需分页/多查询，注意调用限额）；
- 用 `whitelist_dynamic.json` 实际入选票历史做小样本 out-of-sample（贴近真实决策分布）；
- 用 m5 重放（`bt_hypo.py` 口径）消除目标/止损同日双触的先后歧义（本报告已同时给保守/乐观双口径，实盘真值介于其间）。
