## 一、退出规则时间因果性（P0，S8 测试通过）

引擎在入场日预扫描未来 K 线登记计划出场日，形式上用了未来数据。S8 合成数据测试证明其**数学等价于逐日流式触发**（取首个触发日+1）：

- **S8-1 截断一致**：窗口截到第 T 日后，出场日≤T 的交易与全窗口运行逐字段一致（28 笔）；
- **S8-2 扰动不变**：T 日之后行情整体 ×5 改乱，T 日前全部信号与订单意图逐字段不变（20 笔在界内）；界外订单确实随未来行情变化（8 笔）——证明既不前视、也非写死；
- **S8-3 解析一致**：移动触发条件出现的日期后，每笔出场与"扫描区间首个触发日+1，否则到时退出"的解析期望完全吻合（14 笔中 11 笔按期望变动）。

出场日决策的数据依赖已写明：close[xd-1]（前收）、open[xd]（开盘）、susp[xd]。固定持仓期限从**实际入场日**起算（xe = e + max_hold）。入场侧：信号用 T-1 收盘特征，执行用 T 开盘 vs T-1 收盘（开盘近似涨停跳过）——T 收盘信号 → T+1 开盘执行的口径全链路无未来函数。
