`tests/test_s8_streaming_diff.py`（S8d/S8e）验收：

  完全一致（同日订单按 (e, code) 排序消除撮合顺序歧义）；
- S8e 延迟成交场景：现金仅够 50% 目标、卖出次日才释放资金——首笔成交日
  e0=4 晚于信号日 s=2，两实现均在 e0+3=7（自实际成交日起算）退出，
  证明固定期限自**实际成交日**起算。

**对拍中发现并已修复引擎真实缺陷**：出场日末段收益（open[xd-1]→open[xd]）

重建 champion（IS -3.3%、DEV +140.2%、Sharpe 3.16，快照 v5 两遍复现一致）。
